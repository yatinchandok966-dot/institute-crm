# EduPulse CRM - Enterprise Institute & Academy Management OS

A full-stack, enterprise-grade CRM and Operations Management OS built for educational institutes, coaching academies, and coding bootcamps.

---

## 🚀 Technology Stack
- **Frontend**: React 18, Vite, Tailwind CSS (with Dark/Light Mode), Lucide Icons
- **Backend**: Node.js, Express.js (REST API, Connection pooling via `pg`, in-memory resilient fallback)
- **Database**: PostgreSQL (Structured relational schema with complete DDL & seeds)

---

## 🌟 Modern Features & System Architecture

### 1. 📊 Executive Operations Command Center Dashboard
- **Executive KPI Cards**: Active Students (+14.5% trend), Monthly Inquiries (28.4% conversion), Cohort Seat Fill Rate (82% avg), and Monthly Revenue Collection (with sparklines).
- **Executive Urgency Alert Center**: High-priority alert banner highlighting overdue installments, hot leads requiring follow-up, and batches approaching capacity.
- **Revenue Timeline Chart**: Interactive 6-month tuition fee collection vs target trajectory.
- **Inquiry Conversion Funnel**: Visual drop-off analysis from raw leads to paid enrollments.
- **Recent Inquiries & Batch Occupancy**: Instant actions for phone calls, WhatsApp messaging, and stage updates.

### 2. 👥 Leads & Inquiries CRM Pipeline
- **Kanban Board & Table View Switcher**: Move inquiries across stages (*New*, *Contacted*, *Demo Booked*, *Follow-up*, *Converted*).
- **Lead Priority Tags**: Hot (🔥), Warm (☀️), Cold (❄️).
- **Direct WhatsApp Messaging**: Instant click-to-chat (`https://wa.me/...`) with pre-composed greetings.
- **Counselor Assignment & Notes**: Assign counselor leads and record requirements.

### 3. 📚 Courses & Curriculum Catalog
- **Interactive Course Cards**: Filter by category (Software Dev, Data & AI, Design, Marketing, Cyber Security).
- **Curriculum Syllabus Modules Accordion**: Inspect weekly syllabus outlines and capstone project details.
- **Add Course Modal**: Create new certification tracks with customizable duration and fees.

### 4. 📅 Batches & Cohort Scheduling
- **Live Seat Occupancy Gauge**: Color-coded meters showing filled vs available seats.
- **Cohort Metadata**: Mode (Hybrid, Online, Classroom), room number, lecture timings, and instructor profile.
- **Schedule New Batch Modal**: Schedule upcoming cohorts and set seat caps.

### 5. 🎓 Students & Admissions Directory
- **Student Roster**: Filter by enrollment status, fee status (*Paid*, *Partial*, *Overdue*), and attendance rate.
- **Official Digital Student Identity Card**: Generate printable student passes with student photo, barcode, and course details.

### 6. 💳 Fees, Invoicing & Accounts
- **Financial Accounts Overview**: Collected Revenue, Pending Installments Due, and 83.3% Collection Efficiency.
- **Record Fee Payment Modal**: Collect tuition installments via UPI, Netbanking, Credit Card, or Cash with auto-generated receipt numbers (`RCP-2026-XXXX`).
- **Official Printable Payment Receipt Modal**: High-resolution receipt slip for students.

### 7. 📋 Daily Batch Attendance Register
- **Interactive Daily Register**: Select batch and date, toggle Present (P), Absent (A), or Late (L).
- **Bulk Actions**: One-click "Mark All Present" and live session attendance percentage.

### 8. 💬 WhatsApp & Communication Hub
- **Pre-Built Interactive Templates**: Demo Class Invitations, Fee Reminders, Batch Commencement Alerts, and Absentee Notifications.
- **Dynamic Parameter Replacement**: Automatically fills student name, course, balance due, and dates.
- **Click-to-Send**: Launches WhatsApp Web/App with message ready to dispatch.

### 9. 📈 Executive Financial & P&L Analytics
- **Program Profitability Breakdown**: Revenue generated by course.
- **Counselor Leaderboard**: Conversion rankings and revenue credited per counselor.
- **Marketing Channel ROI**: Ad spend vs converted students across Google Ads, Instagram, Referrals, and SEO.

### 10. ⚡ Command Palette & Global Search (`Ctrl+K` / `⌘K`)
- Quick launcher to navigate between modules, trigger modals, and toggle theme.
- **Dark / Light Theme Toggle**: Persistent theme switcher in the header.

## ⚡ Quick Start

### 1. Start Express Backend
```powershell
cd server
npm start
# or: npm run dev
```
*Backend runs on `http://localhost:5000`*

### 2. Start React Frontend
```powershell
cd client
npm run dev
```
*Frontend runs on `http://localhost:3000`*
